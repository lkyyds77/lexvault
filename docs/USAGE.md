# 使用指南

## 1. 选择隐私模式

首次启动默认使用“纯本地模式”，不需要 API Key。该模式不会调用模型 API，文档、问题和检索内容都不会离开设备。

如果需要让远程模型对命中内容做语言精炼，可在“隐私与设置”关闭纯本地模式。此时问题和所有通过相关性筛选的精简命中片段会发往你配置的服务，完整文件不会上传。命中条数没有固定上限，因此大范围问题可能增加 Token 消耗或触及模型上下文限制。

### DeepSeek

| 配置项 | 值 |
|---|---|
| API 地址 | `https://api.deepseek.com` |
| 模型名称 | `deepseek-flash` |
| API Key | DeepSeek 控制台创建的密钥 |

填写后点击“测试模型连接”。如果提示模型不可用，应用会同时列出当前账号可用的模型名称。

### 其他服务

可使用支持 `/chat/completions` 和 Bearer API Key 的 OpenAI 兼容服务。API 地址应填写到版本根路径，不要包含 `/chat/completions`。

## 2. 准备法律文件

建议从[国家法律法规数据库](https://flk.npc.gov.cn/)下载官方 Word 或 PDF：

1. 在官方数据库搜索法规名称。
2. 确认页面中的时效性、公布日期、施行日期和历史沿革。
3. 下载 WPS/Word 版本或公报原版。
4. 回到律知库导入文件。

支持格式：`.pdf`、`.docx`、`.doc`、`.txt`、`.md`。扫描版 PDF 需要先进行 OCR。

可以使用“导入文件夹”递归导入文件夹内所有支持格式；符号链接会被忽略，已经导入的同一路径会自动跳过。

### 多级目录分类

1. 在文档库的“导入到目录”中选择目标目录。
2. 点击“导入文件”或“导入文件夹”，新文档会直接归入所选目录。
3. 选择已有目录后点击“新建子目录”，可继续增加任意层级。
4. 点击目录名称可以筛选该目录及全部子目录的文档；点击名称前的箭头可展开或折叠子目录，折叠状态会自动记住。
5. 每份文档右侧的目录下拉框可用于移动已有文档。

应用预置“刑事、民事、公益诉讼、案管”等一级目录；“刑事”下预置“刑法、刑事诉讼法”，“刑法”下按罪名章节细分。升级前导入的文档会归入“未分类”，不会丢失。

## 3. 提问

问题尽量包含明确的罪名、法规名或法律概念，例如：

- `聚众斗殴罪的法定刑是什么？`
- `包庇罪的构成要件是什么？`
- `船舶油污损害赔偿范围包括哪些？`

页面先显示直接结论。点击“查看依据、效力信息与法条原文”后，才会展开本地命中的上下文、日期及原文。

## 4. 快捷键与开机启动

- 默认全局快捷键：`Ctrl+Shift+K`
- 可在“设置”中修改快捷键
- “开机自动启动”启用后，登录 Windows 时应用会在后台启动
- 关闭窗口时应用会隐藏到后台；需要彻底退出时可通过任务管理器结束“律知库”进程

## 5. 故障排查

### `fetch failed`

先在“设置”中点击“测试模型连接”。使用 DeepSeek 时确认：

- API 地址为 `https://api.deepseek.com`
- 模型为 API 返回的可用模型，例如 `deepseek-flash`
- API Key 有效且账户可正常调用 API
- 防火墙或代理没有阻止应用联网

如果不希望发生任何模型网络请求，请开启纯本地模式。远程模型连接失败时，应用仍会显示本地命中的法条原文。

### 检索不到内容

1. 在文档库确认文件已导入且片段数大于零。
2. 打开原文件，确认内容是可选择的文本而非扫描图片。
3. 使用法规正文中出现的准确关键词提问。
4. 删除并重新导入经过 OCR 的文件。

### 日期或时效性显示“未标明”

下载文件可能不包含官方详情页上的元数据。程序不会根据文件名猜测效力状态，请返回官方数据库详情页核对。

## 6. 数据备份

默认用户数据目录：

```text
%APPDATA%\lexvault
```

退出应用后复制该目录即可备份文档索引和设置。API Key 使用当前 Windows 用户的系统凭据加密，在其他电脑或用户下可能无法解密，需要重新输入。
